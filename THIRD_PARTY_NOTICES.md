# Third-party data

## wger exercise data

Exercise metadata is synchronized from [wger](https://wger.de).

Each generated record preserves its upstream license name, URL and author in `src/generated/wger-exercises.json`. Entries can use different Creative Commons licenses; attribution and share-alike requirements must be reviewed before distributing modified exercise data or media.

wger application code is AGPL-3.0-or-later. Easyfit consumes the public exercise API and does not copy the wger application code.
